# RitwikCodes.github.io

Personal landing page for linking multiple websites hosted with GitHub Pages.

## Publish this site

1. Create a GitHub repository named `RitwikCodes.github.io` under the `RitwikCodes` account.
2. Add the files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Visit `https://ritwikcodes.github.io/` after the Pages deployment completes.

The page links to the existing ProfLine project at `https://ritwikcodes.github.io/FWD.023/`. To feature another site, add a project card in `index.html` with its public Pages URL.
